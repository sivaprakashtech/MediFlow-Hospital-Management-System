# 🏥 MedFlow HMS

### Enterprise Hospital Management System

<p>
A modern, enterprise-grade <b>Hospital Management System</b> built with
<b>React 18</b>, <b>TypeScript</b>, <b>Vite</b> and <b>Tailwind CSS</b>.

Designed as a premium portfolio project showcasing
AI-inspired healthcare dashboards, role-based access,
modern SaaS UI, analytics, responsive design,
and enterprise architecture.
</p>
